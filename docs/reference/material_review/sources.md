# 材料物性レビュー：文献の目録

材料物性レビュー（`docs/reference/material_review/`）で使う文献の、どこに何が載っているかの一覧。
文献そのものは非公開リポジトリ（`docs/reference/papers/`）にある（`docs/reference/README.md`）。

- **ページ番号は PDF のページ番号**（ファイルを開いたときの通し番号）。本に印刷されているページ番号とは違うので、両方を書く。
- 「熱」は熱伝導率・比熱・密度、「平衡」は平衡含水率、「透湿」は透湿率（湿気伝導率）、「拡散」は液水（水分）拡散係数。
- 教科書 3 冊は、紙をスキャンした画像の PDF で、文字として取り出せない。数値は画像を見て書き写す。

作成: 2026-10-21
