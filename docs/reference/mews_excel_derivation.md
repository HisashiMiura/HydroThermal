# materials_mews_ashrae.xlsx の MEWS 材料（No.1〜42）の値はどう作られたか

作成: 2026-10-19（Claude Code による調査）
対象: `modules/materials_mews_ashrae.xlsx` の「データファイル用」シート、材料名が「MEWS」で始まる No.1〜42
出典資料: RR-110、homepages.doc（入手先は 2 章）
照合スクリプト: `docs/reference/mews_check/`（再現方法は 7 章）

ASHRAE の材料（No.43〜80）は、出典の報告書（RP-1018）が手元にないため、別の資料で扱う。

---

## 1. まとめ

- **出典**：MEWS の 42 材料は、NRC カナダ IRC の報告書 RR-110「Summary Report from Task 3 of MEWS Project – Hygrothermal Properties of Several Building Materials」（Kumaran ほか、2002年3月）の 11 章に、すべて対応づけられた。
- **値の作り方**：Excel の値は、報告書の「測定値の表」をもとに、Excel を作った人が単位を直し、回帰式の係数を求めたものと考えられる。報告書そのものには回帰式の係数は載っていない。
- **よく合うもの**：密度・熱伝導率・比熱・透気率はほぼ全材料で一致した（違いは丸めの範囲）。透湿率と液水拡散係数も、多くの材料で表の値と数 % 以内で合った。
- **合わないもの**（5 章）：
  - 液水拡散係数：**No.3 Plywood**（Excel は表の 1/3〜1/12）、**No.24〜26 Stucco**（Excel は表の数十〜数十万倍）、No.20・23 Mortar（約 1.3〜1.5 倍）。
  - 透湿率：No.15 Brick II（低湿で表の 1/5）、No.35 Siding I（表の 0.4〜1.0 倍）、No.28 Fibreboard II（係数 c と d が同じ値）。
  - 平衡含水率：**No.1 Aerated Concrete と No.2 OSB の低湿域**（RH 50% で Excel が表の 1/2700 と 1/4）。No.28 Fibreboard II だけ、ほかの Fibreboard と違って真空飽和に合わせた形。
- **ほかの材料の値を写したと見られる定数**：No.41 Gypsum と No.29 Fibreboard III の液水拡散係数 a、No.3 Plywood の区間2、No.26 Acrylic Stucco の区間3（5.3 節）。
- **範囲分け数 0 の a**：ln(99999)（「測っていない」の印）と ln(10⁻¹⁶)（実質 0）であることが、出典資料から確かめられた。
- **プログラムへの影響**：液水拡散係数の定義（RR-110 の式(5)）から、液水伝導率に直すときに掛ける密度は**材料の乾燥密度**であり、水の密度ではない（6 章）。

## 2. 調べ方と限界

### 出典資料の入手先
出典資料は他の人が書いたものなので、リポジトリには入れていない。次の場所から入手できる（2026-10-20 に確認）。

- `IRC_report_rr110.pdf`：Kumaran, M.K., Lackey, J.C., Normandin, N., van Reenen, D., Tariku, F. (2002) "Summary report from Task 3 of MEWS Project at the Institute for Research in Construction: hygrothermal properties of several building materials", IRC Research Report RR-110（無料）：https://nrc-publications.canada.ca/eng/view/object/?id=82a4a334-a1dd-4701-a32d-d02e4232b39a
- `homepages.doc`：3 つの部分からなる。
  1. IRC の広報誌 Construction Innovation 第8巻第4号（2003年12月）の記事「Results of IRC's material properties studies now available」（Kumaran）：https://nrc-publications.canada.ca/eng/view/object/?id=0e1e4021-5691-48b9-aeea-825135c95a23
  2. IRC のホームページの文章（データの入手方法）：元の場所は http://irc.nrc-cnrc.gc.ca/bes/hygro/dbase.html 。今は公開されていない（2026-10-20 に探したが見つからなかった）。
  3. IRC Hygrothermal Properties Database（ソフト）の説明書の一部（99999 = 測っていない、透気率の換算方法）：今は公開されていない。

### 調べ方
1. RR-110 の PDF から表を文字として取り出し、`mews_check/rr110_tables.py` に書き写した。
2. Excel の「データファイル用」の係数から、プログラムと同じ式（`modules/material_props.py` の部品）で値を計算し、表の値と比べた（`mews_check/check_mews.py`）。比べた結果は `mews_check/output.txt`。
3. 液水拡散係数は、Excel の区間ごとに「ln D を含水率 u の多項式で最小二乗近似」をやり直し、Excel の係数と比べた。

比べた結果は「Excel の値 ÷ 表の値」の比で示す。1 に近いほど合っている。

### 限界
- **PDF の表の崩れ**：取り出した文字では、表の列がずれていたり、数字が離れていたりする箇所がある（表 4.2、5.6、7.5、7.6、8.7、9.4〜9.6、10.1、12.1）。値の並び方から列を判断したが、原本で確かめていない。書き写した値には、表の番号を付けてある。
- **グラフの値は読めない**：PDF をページの画像として見る道具がないため、グラフにしか載っていない値は使っていない。
- **列と材料の対応**：Fibreboard（8 製品）、Siding、メンブレンの一部は、表の列と Excel の材料の対応が表から読み取れない。密度の並びと、Excel の式に一番近い列から判断した。
- **Excel を作った人の判断**：回帰に使った点や重み付けは分からない。そのため、「どの点を使ったか」は推測になる。

## 4. 物性ごとの作り方

### 4.1 密度・熱伝導率・比熱・透気率

| 物性 | Excel の値の作り方 | 照合結果 |
|---|---|---|
| 乾燥密度 | 報告書の試験体の密度を、10 kg/m³ 程度に丸めた値（2 試験体あるものは平均） | 全材料で表と 0〜2% の違い |
| 熱伝導率 | 平均温度 約 24 °C のときの測定値（2 試験体あるものは平均） | 全材料で一致（違い 0.5% 以下） |
| 比熱 | 報告書に「IEA Annex 24 の値」として書かれている値（Aerated 840、OSB・Plywood・Fibreboard・Siding 1880、Brick 800、Mortar 900、Stucco 840） | 一致 |
| メンブレンの密度 | 表 4.1 の「単位面積あたりの質量 ÷ 厚さ」（例：IA は 83 g/m² ÷ 0.23 mm = 361 kg/m³ → Excel 360） | 10 製品とも一致（丸めの範囲） |
| 透気率（m²） | 報告書の値 kg/(m·Pa·s) ÷ 空気の密度 1.2 × 空気の粘性係数 1.7×10⁻⁵（homepages.doc の説明どおり） | No.1：4.9×10⁻⁹ ÷ 1.2 × 1.7×10⁻⁵ = 6.94×10⁻¹⁴ → Excel 6.9×10⁻¹⁴ |

### 4.2 透湿率（Excel の「湿気伝導率」）

**式**：δp = a · x^b · exp(c · (1 − x^d))（x：相対湿度 0〜1、単位 kg/(m·s·Pa)）

**作り方**：報告書の「RH ごとの透湿率の表」に、この式を当てはめて係数を求めたと考えられる。表の種類によって、次のように直してある。

| 報告書の表 | 直し方 | 材料 |
|---|---|---|
| 透湿率 kg/(m·s·Pa) | そのまま | Aerated、Brick、Mortar、Stucco、Fibreboard、SPF、EIFS |
| 下限・上限の2列 | 2 列の平均（算術平均でも幾何平均でも、違いは 1% 以内） | OSB、Plywood |
| パーミアンス kg/(m²·s·Pa) | × 厚さ | Siding（表 9.1 の厚さ）、メンブレン（表 4.1 の厚さ）、Gypsum（RH 80% の値 4.43×10⁻⁹ × 13 mm = 5.76×10⁻¹¹ → Excel 5.8×10⁻¹¹） |
| RH によらず一定 | a に一定値、b〜d を 0 | メンブレン IVA, VII, VIII, IX、EIFS、Gypsum |

**照合結果**（Excel ÷ 表、RH 10〜100%）

| 合い方 | 材料 |
|---|---|
| ±3% 以内 | No.1、14、16、17、20〜27、30〜34、37、39、40、42、メンブレン IVA・VII・VIII・IX、Gypsum |
| ±10% 以内 | No.2 OSB（0.99〜1.06、9 点すべてが下限〜上限に入る）、No.18 Brick V（0.94〜0.99）、メンブレン IA（0.94〜1.05）、II（0.97〜1.08）、III（0.92〜1.02） |
| ±16% 以内 | No.3 Plywood（0.84〜1.07、9 点中 8 点が下限〜上限に入る） |
| 低湿側だけ大きくずれる | No.19 Brick VI（RH 10% で 0.66、ほかは ±8%）、No.36 Siding II・No.38 Siding IV（RH 10% で 0.24・0.53、ほかは ±22%）、メンブレン VA（0.79〜1.14）、VC（0.88〜1.13）、VI（RH 10% で 0.08） |
| 全体にずれる | **No.15 Brick II**（RH 10% で 0.20、RH 100% で 1.14）、**No.35 Siding I**（0.37〜0.99）、**No.28 Fibreboard II**（RH 10% で 1.4〜1.7） |

低湿側のずれは、表の値がほぼ一定（または RH 10% と 20% で同じ値）なのに、この式は x → 0 で 0 に近づく形のため、当てはめきれないことによると考えられる。

### 4.3 平衡含水率

**式**：u = a · x^b · exp(c · (1 − x^d))（Parameter = 1。MEWS の材料に Parameter = 2 はない）

**作り方**：報告書の吸湿・放湿・加圧板の値に当てはめたと考えられる。homepages.doc には「Absorption/Desorption/Suction Isotherm (approximated as a single curve)」とあり、吸湿と放湿を分けずに1本の曲線で表している。加圧板の値は、報告書の式(4)で相対湿度に直せる（例：吸引圧 3×10⁵ Pa → RH 99.78%、1×10⁵ Pa → RH 99.93%（22 °C））。

### 4.4 液水拡散係数

**定義**（RR-110 の式(5)、p.5）

```
Jl = − ρ0 · Dw · grad u
  ρ0: 乾燥した材料の密度
  u : 含水率（水の質量 / 乾燥した材料の質量, kg/kg）
  Dw: 液水拡散係数, m²/s
```

**式**（Excel）：D = exp(a + b·u + c·u² + d·u³ + e·u⁴ + f·u⁵ + g·u⁶)（u：kg/kg、D：m²/s）

**単位の直し方**：報告書の表は、含水率を kg/kg で書いたもの（Aerated、EIFS）と、含水量 kg/m³ で書いたもの（それ以外）がある。kg/m³ の表は、Excel の乾燥密度で割って kg/kg に直してある。例えば No.14 Brick I は、50 kg/m³ ÷ 2300 = 0.0217 kg/kg のとき表 3.57×10⁻¹² に対し Excel 3.54×10⁻¹²。

**範囲分けの作り方**：No.1 Aerated Concrete（範囲分け数 3）を例にすると、次のようになっている。

| 区間 | 含水率 | Excel の式 | 意味 |
|---|---|---|---|
| 1 | 〜0.087 | 定数 exp(a) = 8.70×10⁻⁹ | 表の最初の点（0.087 kg/kg で 8.72×10⁻⁹）の値で一定 |
| 2 | 0.087〜0.54 | 4 次式 | 表の 20 点に当てはめた式 |
| 3 | 0.54〜1.3 | 定数 exp(a) = 5.20×10⁻⁸ | 表の最後の点（0.543 kg/kg で 5.15×10⁻⁸）の値で一定 |

つまり、**測った範囲の外は、端の値で一定として延ばしている**。最後の区間の上限（1.3）は、報告書の飽和含水率（全飽和 1.72、毛管飽和 0.83）とは一致しない。

ほかの材料も同じ作りで、範囲分け数ごとに次のように使い分けている。

| 範囲分け数 | 作り | 材料 |
|---|---|---|
| 0 | 拡散係数なし（a に「測っていない」などの印） | メンブレン（No.4〜13）、No.29、33、35、37、41、42 |
| 1 | 全範囲で1本の式（範囲(大) = 0） | Brick（No.14〜19）、Mortar（No.20〜23） |
| 2 | 多項式 ＋ 上側の定数 | OSB、Plywood、EIFS（EIFS は 下側の定数 ＋ 多項式） |
| 3 | 下側の定数 ＋ 多項式 ＋ 上側の定数 | Aerated、Stucco、Fibreboard、Siding |
| 4 | No.27 だけ。係数は 3 区間分しかない | No.27 Fibreboard I |

## 5. 合わない点・疑問点

### 5.1 No.3 Plywood の液水拡散係数が表 3.3 と合わない
- Excel の式の値は、表 3.3（下限・上限の幾何平均、乾燥密度 500 で kg/kg に直した）の 0.08〜0.36 倍。
- 割る密度をどう変えても、合う値は見つからなかった（例：水の密度 1000 で割ると 0.15〜0.71 倍）。OSB の式を当てはめても合わない。
- 区間2 の定数（2.80×10⁻¹⁰）は、**No.2 OSB の区間2 と全桁一致**し、OSB の表の最後の値と同じ。Plywood の表の最後の値（約 9.4×10⁻¹⁰）とは違う。
- **追記（2026-10-21）：Excel の No.3 Plywood は、OSB の表 3.4 を合板の密度 500 で kg/kg に直して当てはめたものと見られる。** Excel の式を含水量（含水率 × 500）に直すと、OSB の表 3.4 の 0.95〜1.17 倍でぴったり合う（含水量 30〜400 kg/m³）。区間1 の上限 1.2 kg/kg も、OSB の表の最後の含水量 600 kg/m³ ÷ 500 で説明できる（OSB の区間1 の上限 0.92 も 600 ÷ 650）。前の版では境目 1.2・1.6 を加圧板の値（1.23、1.60）と推測していたが、こちらのほうが自然。詳しくは `material_review/01_wood_boards.md` 3.3 節。
- なお、RR-110 の Plywood・OSB の拡散係数は「across the edges」（小口から吸水）で測った面内の値で、厚さ方向の吸水係数（表 3.5：0.0026・0.0022 kg/(m²·s^½)）から見積もった値（10⁻¹¹ 程度）より 1〜2 桁大きい。

### 5.2 No.24〜26 Stucco の液水拡散係数が表 7.6 と合わない
- 表 7.6 の値は 10⁻¹⁵〜10⁻⁹ と急に増えるが、Excel は 10⁻⁹ 前後でほぼ平ら。例えば Lime Stucco の u = 0.03 で、表 9.5×10⁻¹⁵ に対し Excel 2.2×10⁻⁹。
- 割る密度を変えても合わない。
- 区間の上限（Lime 0.16、Portland 0.12、Acrylic 0.16）は、表 7.5 の真空飽和の含水率（0.16、0.12、0.157）と一致する。範囲だけは報告書に合わせ、係数は別のデータから取った可能性がある。
- Acrylic Stucco の区間3 の定数（2.29×10⁻⁹）は、No.27 Fibreboard I の区間1 と全桁一致する（5.3 節）。

### 5.4 透湿率の当てはまりが悪い材料
- **No.15 Brick II**：表 5.2 の値はほぼ直線的に増える（1.51〜2.15×10⁻¹²）が、Excel の式は低湿で表の 1/5 になる。ほかのレンガの列にも合わない。
- **No.35 Siding I**：表 9.5 のパーミアンス × 厚さ に対して 0.37〜0.99 倍。
- **No.28 Fibreboard II**：係数 c と d が同じ値（−0.27904）。d が負なので x = 0 で計算できない（Excel にもコメントあり）。表とは低湿で 1.4〜1.7 倍ずれる。

### 5.5 平衡含水率の低湿域（No.1 Aerated Concrete、No.2 OSB）
Excel の式は、高湿域（RH 88% 以上、Aerated は放湿の値）には合っているが、低湿域を大きく下回る。熱・水分の計算では、ふだんの湿度（RH 40〜80%）での含水量が少なく見積もられることになる。

### 5.6 No.27 Fibreboard I の範囲分け数 4
係数と範囲は 3 区間分しかない。区間3（0.32〜0.53）は 4 次式で、その上の定数の区間がない。表 8.7 の Paper Facer の列の値（崩れて読めない部分を含む）と、照らし合わせきれていない。
ほかの Fibreboard（No.28・30〜32・34）はどれも「下側の定数 ＋ 測った範囲の多項式 ＋ 上側の定数」の 3 区間である。No.27 は測った範囲を 2 本の多項式（区間2・3）に分けたため、上側の定数の区間4 が、区間3 までしか欄のない Excel に入りきらなかったと見られる（推測）。
**プログラムでの扱い（2026-10-20 に決定、対応済み）**：範囲分け数 3 として読み、区間3 の上限 0.53 を超える含水率は、0.53 での値 3.7×10⁻¹⁰ m²/s で一定とする（6 章 3 の決まり）。欠けている区間4 を「端の値で一定」で補うことになる。読み替えたときはログ（WARNING）に出す。Excel の値は変えていない。影響するのは RH 99.88% より上だけ。

## 6. このプログラムへの影響

1. **液水伝導率に掛ける密度（HANDOFF の未決事項 1）**
   RR-110 の式(5) `Jl = −ρ0·Dw·grad u` から、水分化学ポテンシャル勾配に対する液水伝導率は `ρ0 · Dw · du/dμ` になる。**掛ける密度は材料の乾燥密度 ρ0** で、今の `thermo_dynamics.get_lambda_dsh_mu_l` が掛けている水の密度（998）ではない。新しい Excel のデータを使うときは、乾燥密度を掛ける必要がある。旧 Excel（Fortran 版の構造用合板1）の拡散係数がどちらの定義かは、この資料からは分からない。
2. **範囲分け数 0 は「液水が移動しない」として扱う**。a は「測っていない」（ln 99999）などの印で、拡散係数の値ではない。
3. **区間の外の扱い（2026-10-20 に決定、対応済み）**
   Excel は、測った範囲の外を「端の値で一定」として延ばしている。上限の値そのもの（例：Aerated の 1.3）がどこから来たかは分からない。
   プログラム（`material_loaders._liquid_diffusivity_from_ranges`）では、**最後の区間の後ろに「上限から +∞ まで、上限での値で一定」の区間を足す**（多項式の材料は上限での値を計算して定数にする）。Excel の値は変えていない。RH 100% の平衡含水率が最後の区間の上限より大きく、計算結果が変わるのは 9 材料（MEWS の No.27・28、ASHRAE の No.49・58・63・66・67・73・74。No.27 は範囲分け数 3 として読んだ場合）で、これらはログに出す。理由：測った範囲より上を「端の値で一定」とする Excel の作り方に合い、上限で値が急に変わらず、範囲の外で多項式を使わないため（0 にすると RH 100% 近くで液水が急に動かなくなる。式をそのまま延ばすと No.49 では 10⁻⁸¹ まで下がる）。
4. **使うときに注意が必要な材料**：No.3 Plywood と No.24〜26 Stucco の液水拡散係数、No.1・2 の平衡含水率の低湿域、No.15・28・35 の透湿率。

## 7. 再現方法

```bash
# プロジェクトのフォルダで
python docs/reference/mews_check/check_mews.py
```

- `mews_check/rr110_tables.py`：RR-110 の表を書き写したもの（表の番号、ページ、崩れていた箇所の判断を記載）
- `mews_check/check_mews.py`：Excel の係数で計算した値と表の値を比べる。液水拡散係数は、区間ごとに近似し直した係数も表示する
- `mews_check/output.txt`：このレポートを書いたときの出力

吸引圧から相対湿度への換算（RR-110 の式(4)）には、水のモル質量 0.018015 kg/mol、気体定数 8.314 J/(mol·K)、水の密度 1000 kg/m³、温度 22 °C を使った。
